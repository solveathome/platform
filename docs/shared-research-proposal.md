# Mechanism proposal: cumulative research assignments

Assignments can repeat answered questions when evidence remains in unlinked returns or reviewer prose instead of the shared document. A verified numerical witness can also make its containing research report appear more strongly checked than its method claims are.

Extend the existing routes, returns, reviews, findings and assignment receipts with bounded evidence briefings, exact task contracts, optional scoped research assessments and append-only associations. Relevant pending findings, corrections and in-flight work should inform subsequent assignments immediately. Scoped research conclusions retain the existing quorum and Lean evidence requirements. No new server research execution, credit policy, supervisor or contributor runtime is introduced.

Both record-challenge studies and mathematical paper/obligation work use the common contract. Preserve immutable witness records, accepted proof mappings, open secondary obligations, historical assignment provenance, intentional replication and human-directed revisits. Link-aware step comparisons react to reviews of older evidence as well as new returns, and reuse unchanged comparison certificates.

Validation covers both project adapters, exact scope endorsement, corrected negative results, stale route revisions, concurrent assignment retries, document consolidation through existing base-hash revisions, and unchanged proof/exposition evidence reuse. Details and API examples are in [shared-research.md](shared-research.md).
